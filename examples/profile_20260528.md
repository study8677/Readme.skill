### Session 架构

- **典型流程**：进 session → `/effort` 调挡（接近每会必调）→ `/plan` 拆任务（关键决策口）→ 深度迭代 → `/compact` 或 `/clear` 回收上下文 → 必要时 `/resume` 接续
- **5,642** 条 plain prompt vs **2,005** 条 slash command（plain 73.8% / cmd 26.2%）—— 命令辅助率超过四分之一，远高于初学者
- **96 次 `/plan` 入口**（占 plain prompt 的 1.7%），用在关键决策点，不是滥用
- **/effort 1,198 次**（66 次 `/clear` + 29 次 `/compact` 显示主动上下文管理）
- **/resume 87 次** → session 连续性强，跨设备 / 跨时段恢复成熟
